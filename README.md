# ChestXRayDetection

Final MIT Computer Vision Project.

This project investigates the robustness of chest X-ray classification using the NIH ChestXray14 dataset, training both binary and multi-level DenseNet-121 classifiers and evaluated on VinDr-CXR for external testing across institutions. An entropy-gated test-time adaptation method updates this model during development using only low-uncertainty samples, with the goal of improving robustness and generalization in chest X-ray modeling. 

While all code and results are here, images are not uploaded due to it not being open source and needs permission.
